## Introduction

**libpath** provides file-system path parsing and comparison utilities.

**libpath.Python** is the **Python** implementation. It supports **Python 2.7** and **Python 3.8+**. This repository is a packaging skeleton; the path API is not implemented yet.


## Installation

Install via **pip**:

```
pip install libpath
```

Use via **import**:

```Python
import libpath

print(libpath.__version__)
```
